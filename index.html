使用场景

跨境协作与资料访问

远程会议、代码仓库、云文档和学术数据库对延迟与稳定性更敏感。把系统代理或规则分流指向香港、新加坡或日本节点，可减少握手失败。基础版即可覆盖日常办公；多人共用请选择团队版，以免挤占设备名额。

流媒体与内容创作

旗舰版标注全节点原生流媒体解锁，适合需要切换地区片库的观看与素材收集。建议在客户端里为视频域名单独走对应区域节点，避免全局模式占用过多流量。遇到版权库校验失败时，先更新订阅再更换同区域备用节点。

游戏与实时语音

IPLC 专线主要用于对抖动敏感的对战与开黑。选择离游戏服更近的专线，关闭多余的 UDP 转发实验项，通常比盲目选“最快延迟”更稳。语音软件可与游戏走同一出口，减少防火墙误判。

出行与多设备同步

手机、电脑、平板同时在线时，请确认套餐设备上限。订阅同一链接即可，不必为每台机器单独购买。公共 Wi-Fi 环境下先连上加速器再登录邮箱与网银相关页面。

配置流程

自由壁虎(FreeGecko)把接入拆成可核对的六步。按顺序做完，客户端里应能看到节点列表并成功连通。若某一步失败，停在该步对照 FAQ，不要同时更换客户端、订阅和系统代理，以免无法判断原因。

1确认需求与套餐

估算每月流量、同时在线设备和是否需要 IPLC。轻度浏览选基础版；流媒体加游戏选旗舰版；工作室或多成员选团队版。

2完成订阅获取链接

在官网订单完成后，用户中心会给出通用订阅地址。复制完整链接，不要在聊天软件里折行。该链接用于导入，不是浏览器直接打开的网页。

3安装对应客户端

Windows 可用 Clash 系或 v2rayN，macOS 可用 Clash Verge 或 Surge，Android 可用 Clash Meta，iOS 常用 Shadowrocket 或 Quantumult X。只从本页客户端下载区进入官方安装说明。

4导入订阅并更新

选择“从 URL 导入/添加订阅”，粘贴链接后手动更新一次。看到港日美新等分组即表示导入成功。若列表为空，检查是否漏掉 https 前缀或混入空格。

5选择节点并测试

先测延迟再看实际打开网页的速度。游戏走 IPLC 分组，视频走解锁分组，普通网页可用负载均衡或自动选择。连通后打开 IP 检测页确认出口地区。

6按场景设置分流

推荐规则模式：国内直连、国外代理。需要应用级代理时，把终端或设计软件加入绕过列表。团队版可提交定制路由，把指定网段固定到 VIP 节点。

配置提示：系统时间必须准确，证书校验失败多半是时间偏差。公司电脑若无法设置 TUN，可改用系统代理端口。更新订阅频率建议每天一次，节点变更后无需重装客户端。

节点与线路说明

普通线路节点池覆盖香港、日本、新加坡、美西、台湾与欧洲入口，适合网页、邮件和中轻度视频。旗舰版在此基础上提供 IPLC 游戏优化分组，减少高峰抖动。团队版另有 VIP 高带宽出口，适合大文件与多人并发。

流媒体策略因套餐而异：基础版解锁常见内容库的基础线路；旗舰与团队强调原生解锁，降低跳转中转带来的地区识别错误。任何线路都不承诺突破特定网站的额外风控，合理切换备用节点即可。

常见问题

如何在自由壁虎(FreeGecko)获取可用的机场订阅链接？

下单成功后进入用户中心复制订阅 URL。该链接用于客户端导入，不要反复在浏览器中打开。若重置链接，旧地址会失效，需要在所有设备上重新导入一次。

官方支持哪些加速器客户端？

桌面端常用 Clash 内核、v2rayN 与 sing-box；移动端常用 Clash Meta、Shadowrocket 与 Quantumult X。只要客户端能识别通用订阅，即可对接。本站提供官网下载指引，不推荐来路不明的修改版。

流量用完或设备超限会怎样？

当月流量用尽后新连接会失败，次月按套餐额度重置，也可临时升级档位。超过同时在线设备数时，新设备无法握手，踢出闲置会话即可。团队版适合共享办公，不必把个人套餐借给过多终端。

怎样确认流媒体已经解锁？

更新订阅后选择对应地区的解锁节点，清空应用缓存再打开。旗舰版与团队版覆盖更完整。若仅个别剧集失败，多半是内容方风控，换同区域节点或等待片刻再试。

游戏加速是否必须使用 IPLC？

对延迟和丢包敏感的对战建议走旗舰版 IPLC 分组；休闲游戏用普通低延迟节点即可。语音与游戏尽量同一出口。团队赛事前先做十分钟在线测试，不要开赛才更换核心。

连不上时按什么顺序排查？

核对系统时间、订阅是否更新、模式是否为规则或全局、本地防火墙是否拦截核心进程。仍失败时换一个地区节点，或临时关闭 TUN 改用系统代理。把客户端日志中的报错原文留给工单，旗舰与团队用户可走优先支持。
